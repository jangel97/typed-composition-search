
\begin{abstract}

As Large Language Model (LLM) agents integrate with increasingly large tool ecosystems, tool routing---determining which tools should be invoked to satisfy a user query---becomes a challenging reasoning problem. Existing approaches formulate routing as direct tool selection, requiring the model to simultaneously identify relevant tools, infer valid multi-step compositions, and ensure that the resulting tool sequence is executable. We argue that this is the wrong abstraction.

We propose \textbf{Typed Composition Routing}, which reformulates tool routing by separating semantic reasoning from compositional reasoning. Instead of selecting executable tools directly, the LLM predicts source and target entity types, while graph search deterministically recovers valid tool compositions from a typed transformation graph. This decomposition shifts the LLM's role from tool selection to entity classification, delegating composition to the graph.

Across four language models, five tool domains (54--170 tools each), and 140 benchmark queries, the proposed formulation improves F1 in all 20 model--domain combinations (average $\Delta$F1 = +0.32) without any training or fine-tuning. The graph structure eliminates hallucinated tool invocations by construction, and a derived recall decomposition shows that end-to-end routing performance separates cleanly into entity prediction accuracy and graph reachability.

\end{abstract}

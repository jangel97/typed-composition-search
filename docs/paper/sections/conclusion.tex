\section{Conclusion}
\label{sec:conclusion}

We presented Typed Composition Search, a reformulation of tool routing as typed entity reasoning.
By modeling tools as typed transformations in a directed graph, we decompose the routing problem into entity type prediction (handled by the LLM) and path recovery (handled by deterministic graph search).

This decomposition improves F1 over direct selection in all 20 model--domain combinations (avg.\ $\Delta$F1 = +0.32), eliminates hallucinated tool invocations as a structural property, and provides an analytical framework where end-to-end recall decomposes into type prediction accuracy and graph reachability.

The typed graph degrades gracefully under prediction errors: incorrect type predictions recover partial tool chains through nearby graph paths rather than producing total failure.
The approach requires no training, fine-tuning, or embedding computation and works with any off-the-shelf language model.

Future directions include automatic ontology construction from API specifications, hybrid retrieval--graph approaches, topology ablation studies, and extension to non-linear composition patterns.
